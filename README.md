# Waypoint

A browser JRPG made with the Anansi SDK. This repository is a static build of `examples/waypoint` from the Anansi project, served with GitHub Pages.
Without an Anansi gateway, NPC replies, city details and the epilogue come from Pollinations' free public AI (pollinations.ai, at most
one reply a minute; the title screen says what is sent there), and side quests and everything else from the game's written fallbacks.
